## Neon Pinball

A self-contained browser pinball game lives in [`pinball/index.html`](pinball/index.html) — open it in any modern browser, no build step.

- **Flippers:** ← / → (or Z / M, A / L, Shift keys) — on touch screens, tap the left / right half
- **Launch:** hold Space (or ↓ / Enter) to charge the plunger, release to fire — on touch, hold the bottom-right corner
- **Pause:** P

Score with pop bumpers, slingshots and drop targets; light all three top rollover lanes (use the flippers to rotate the lit lanes) to raise the score multiplier up to 5x. Each ball gets a 6-second ball save. High score is kept in local storage.
